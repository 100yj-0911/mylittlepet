# 나만의 작은 친구

Windows 바탕화면 위를 돌아다니는 픽셀 펫입니다. 설치할 라이브러리 없이 Python 표준 라이브러리로 실행합니다.

## 실행

Python 3.10 이상과 Tkinter가 설치되어 있으면 `mylittlepet.pyw`를 더블 클릭하세요. 첫 실행 때 강아지와 고양이 중 하나를 고르면, 다음 실행부터 그 친구가 바로 나타납니다. 선택 내용은 `pet_settings.json`에 저장됩니다.

명령 프롬프트에서 실행하려면 이 폴더에서 다음 명령을 사용하세요.

```text
python mylittlepet.pyw
```

## 사용법

- 펫이 화면을 돌아다니며 애니메이션과 말풍선으로 반응합니다. 소리는 재생하지 않습니다.
- 펫을 마우스 왼쪽 버튼으로 잡아 끌어 원하는 위치로 옮길 수 있습니다.
- 펫을 우클릭해 **쓰다듬기** 또는 **간식 주기**를 선택하면 전용 애니메이션과 말풍선으로 반응합니다.
- 우클릭 메뉴의 **마우스 따라다니기**를 켜거나 끄면 마우스 추적과 느린 자유 이동을 전환할 수 있습니다. 설정은 다음 실행에도 유지됩니다.
- 우클릭 메뉴에서 반려동물을 바꾸거나 앱을 종료할 수 있습니다.
- `Esc` 또는 `Ctrl+Shift+Q`를 눌러도 종료됩니다.

펫 창은 다른 창 위에 표시됩니다.
